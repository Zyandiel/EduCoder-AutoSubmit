# 本地代码

这是 `--local` 模式的可选目录。默认 AI 模式无需准备任何文件，自动生成的代码保存在 `logs/run-*/` 中。

以实训完整名称建立目录，第 N 关保存为 `N.cpp`（UTF-8）。真实解答被 Git 忽略，不随仓库提供。

```text
solutions/
└── 你的实训名称/
    ├── 1.cpp
    ├── 2.cpp
    ├── 2.files.json
    └── greeting.h
```

参考 [examples/solutions](../examples/solutions/) 和 [使用指南](../docs/usage.md)。示例网页路径按实际关卡修改，代码需符合题目框架。
