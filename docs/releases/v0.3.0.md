# v0.3.0 — DeepSeek 自动解题

此前需要用户为每关准备本地 CPP 文件。本版本可以直接读取可访问的题目和在线模板，调用 DeepSeek 生成代码，填写后完整回读并执行一次评测。Windows 用户首次双击 `START.cmd`，按提示配置 API Key、登录并选择课程即可开始。

## 新增功能

- 自动发现全部分页中的未完成作业，按真实详情链接区分同名实训。
- 根据当前关卡读取单文件或多文件模板，校验模型 JSON 和允许编辑的路径。
- Windows DPAPI 加密保存 API Key；也支持 `DEEPSEEK_API_KEY` 环境变量。
- 自动选择已安装的 Chrome/Edge，缺少浏览器时安装 Playwright Chromium。
- 生成代码、原代码、评测结果和错误记录保存在本地；每关仅评测一次。
- API 调用次数、上下文大小、输出长度和超时均可配置。
- `python main.py --version` 显示当前版本。

## 安装

需要 Windows、Python 3.11+ 和可用的 DeepSeek API Key。下载本版本的 **Source code (zip)**，解压后双击 `START.cmd`。首次启动自动创建虚拟环境和安装依赖；这不是打包的 EXE。

完整操作说明见 [README](../../README.md) 和 [使用指南](../usage.md)。

## 从 v0.2.0 升级

保留本机 `.auth/`、`config.local.yaml`、`solutions/` 和日志，用新版源码更新程序文件。不要把个人目录上传到仓库。

- **默认行为改变**：缺少 `ai` 配置时也会启用 AI，缺少 `assignment_scope` 时默认扫描全部未完成作业。配置中显式 `enabled: false` 的名称仍会跳过。
- 首次运行会要求配置 DeepSeek API Key；题目和模板会发送到 DeepSeek，并使用你的 API 额度。
- 只处理原来的启用名单：设置 `assignment_scope: configured`。
- 继续使用本地 CPP：执行 `python main.py auto --local`，或设置 `ai.enabled: false`。
- 旧版 `config.yaml` 仍兼容；优先读取 `config.local.yaml`。

## 验证与边界

本地 67 项测试通过，包括真实 Chrome 上的合成页面流程、模拟 API 响应、Windows 密钥加解密、文件映射与评测保护。GitHub Actions 检查 Windows / Python 3.11、Windows / Python 3.14 与 Ubuntu / Python 3.12。真实 DeepSeek Key 与实际课程的完整联调尚未完成，不保证所有线上题目都能通过。

当前适配已观察到的 Monaco 工作区。缺少题意、无法确认文件归属、访问限制或 DOM 改版时会停止当前实训并记录原因。API 无效、额度不足、限流或调用预算耗尽时结束本轮。

默认 `dry_run: true` **仍会填写在线代码、运行评测并可能更新成绩**；最终“提交作业”入口继续关闭。项目不随源码发布账号会话、API Key、个人配置或真实课程解答。
